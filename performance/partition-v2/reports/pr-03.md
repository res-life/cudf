Initial full-matrix readings flagged three unchanged-route cases and one 1,025-row/256-partition case. Six balanced reruns per library, with 101 samples per fixture, gave 0.998x–1.017x for the five unchanged-route controls and 1.143x for the small selected case (the initial isolated matrix reading was 0.666x). No material regression remained confirmed. Matrix means above retain the original readings; reruns are reported separately.

NVIDIA L4; CUDA 12.9.1; Release `-O3`, sm89, per-thread default stream. Rebuilt the affected translation unit through an existing native build and reused compatible unchanged objects. Timing runs use an exclusive GPU with compilation paused, at least 150 ms warmup, and 15 samples per fixture. The harness verifies the loaded library hash, row/column counts, partition offsets, and per-partition row-hash multisets before timing. Input construction/verification are excluded; output destruction is included. Speedup = parent wall-time median / child wall-time median; aggregate speedups are geometric means across workloads. GPU-event geometric means closely track wall time. GPU clocks use the driver's default policy.

The same 132-fixture matrix is used for this PR and its parent: 1K–10M rows; 2/3/4/10 STRING columns; 2/200/256/257 partitions; short/medium/long strings, all-hot/90%-hot/uniform/clustered maps, sliced inputs, nulls, and offset-width/threshold fallbacks. A fixed 117-case regular multi-column STRING cohort is included. Fifty-four fixtures exercise the new gather-based STRING route; the remaining 78 are controls. Two-partition schemas with two or three columns retain the preceding route until the binary/packed STRING PR.
