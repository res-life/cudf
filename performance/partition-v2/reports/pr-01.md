## Incremental performance versus the parent

NVIDIA L4, CUDA 12.9.1, Release `-O3`, sm89, per-thread default stream. Reused compatible unchanged native objects; rebuilt the partition translation unit and linked a separate library. The harness verifies the loaded library hash and partition boundaries, schema, and per-partition row-hash multisets before timing. GPU use is exclusive. Input generation and verification are outside the timed region; output destruction is included. Every timed case has at least 150 ms warmup and 31 samples. Reported speedup is parent wall-time median / candidate wall-time median; aggregate values are geometric means across workloads.

The 42-case matrix contains 20 trivial workloads and 22 ordinary-path controls. Trivial workloads use four INT64 or STRING columns, 1/1,025/1,000,000 rows, 1/17 partitions, and 0%/100% nulls; nontrivial controls include fixed-width, mixed, and multi-column STRING tables and 2/256/257 partitions. STRING lengths range from 0 to 32 bytes.

| Workloads | Cases | Wall-time speedup | Time reduction |
| --- | ---: | ---: | ---: |
| Trivial multi-column STRING | 10 | **8.803x** | **88.6%** |
| Trivial fixed-width | 10 | 5.642x | 82.3% |
| All trivial cases | 20 | 7.048x | 85.8% |

Every trivial case improved in this run: 2.595x–51.341x. These numbers describe the trivial paths, not the later general multi-column STRING optimization.

Three initially noisy ordinary-path controls were repeated six times per library in alternating order, with 101 samples per case. Ratios of the run medians:

| Unchanged-path control | Parent / candidate wall time | Speedup |
| --- | --- | ---: |
| 1,025 rows, four INT64 columns, 17 partitions | 74.8 / 76.2 us | 0.982x |
| 1M rows, four INT64 columns, two partitions, 90% hot bin | 1,055.3 / 1,052.0 us | 1.003x |
| 1M rows, mixed table, 257 partitions, 90% hot bin | 1,448.1 / 1,446.9 us | 1.001x |

No regression was statistically established by those reruns. The sub-0.1-ms control remains noisy: a run-level bootstrap speedup interval is approximately 0.894x–1.171x, so this is not a guarantee of zero regression on every workload. All 31 shared GPU kernels have identical SASS instructions to the parent; only the new trivial paths add kernels.
