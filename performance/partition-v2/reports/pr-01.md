## Regression follow-up

Each controlled comparison uses six independent balanced AB/BA process blocks per library, 301 timing samples per fixture per process, at least 500 ms warmup, an exclusive NVIDIA L4, and SM clocks configured at 2040 MHz. The initial survey restricts the benchmark to CPU 0. Independent confirmation permits CPUs 0,2 on the same physical core so CUDA helper threads can run concurrently; monitoring uses CPUs 1,3. Results under these two CPU-affinity conditions are reported separately and are not pooled. Default GPU clocks are restored after timing.

The paired geomean is the geometric mean of paired parent/child run-median ratios. The secondary median ratio is median(parent run medians) / median(candidate run medians); interval decisions still use all paired log ratios. Intervals use a Student-t 95% interval on paired log ratios across independent process blocks; the 301 within-process samples are not counted as independent replications. The separately declared 2% noninferiority bound requires a lower interval bound of at least 1/1.02. This does not assert literally zero slowdown. Per-fixture intervals are not adjusted for multiple comparisons. An interval containing 1 does not establish absence of a regression.

The 5-fixture initial survey includes all original wall-time point estimates below 0.97x (the root uses its previously flagged controls and two optimized witnesses). Every fixture with an unresolved 2% bound, plus every nominal negative result, received independent confirmation. Production code in this draft is unchanged. Exact direct-parent/head libraries, executable hashes, GPU isolation and output verification are recorded with the raw data.
