The 16-case supplement includes one-partition and partially uniform STRING/fixed-width tables, 1,025/1M rows, 1/2/200/257 partitions, 1/2/4/10 columns, mixed/nullable data, and LIST/STRUCT copy controls. The single-STRING copy control was 1.000x; these reruns are reported separately from the supplemental geometric means above.

NVIDIA L4, CUDA 12.9.1/GCC 14, Release O3, sm89, per-thread default stream. Exact consecutive prefix libraries are selected and hashed. GPU use is exclusive and compilation is paused during timing. Input construction/verification are excluded; output destruction is included. Aggregate speedups are geometric means of parent/candidate median wall-time ratios. The identity supplement uses the same extended native harness for both libraries; that harness only adds partially uniform synthetic fixtures.

## Unchanged-path measurement limits

Default-clock readings in some unchanged paths were bimodal. Four-run balanced controls produced 0.904x for an unchanged STRUCT partition workload (run-level bootstrap interval about 0.803x–1.013x), and 0.844x for an unchanged fixed-width workload (0.663x–1.076x). A separate four-run 2040-MHz matched-clock diagnostic gave 0.994x (0.901x–1.139x) and 0.925x (0.913x–1.475x), respectively. Clock settings were restored afterward.

The intervals include 1, so neither result is presented as an established algorithmic regression or a win. Keep these controls as a follow-up before promoting the draft; this report does not claim universal zero regression. Known identity-copy regressions were addressed by retaining the preceding copy routes, rather than hiding them in an aggregate.
