NVIDIA L4, CUDA 12.9.1/GCC 14, Release O3, sm89, per-thread default stream. Affected native code is rebuilt through an existing compatible native build; unchanged objects are reused. Each comparison uses exact consecutive production prefixes, with loaded-library/executable/fixture hashes checked and an exclusive GPU. Compilation is paused during timing. At least 150 ms warmup and 31 samples per core fixture; output destruction is timed, input construction and output verification are excluded. Speedup is parent median wall time / candidate median wall time; aggregates are geometric means across workloads. GPU clocks use the driver's default policy.

The shared 96-case matrix covers original policy leaves and boundaries: 1,024 rows, 1M fixed-width crossover, 4M STRING crossover, 15/16 partitions, 256/257 partitions, 1/2/3/4/8/10 columns, INT32/INT64/DECIMAL128 storage, sparse/dense nulls, uniform/hot/clustered maps, sliced inputs, nullable/mixed/nested schemas, output-offset fallback, one-row/one-partition/all-null controls. The exact same matrix and native executable are used for each compared pair. Cohorts are scoped to the newly introduced route; their speedups must not be multiplied across unrelated cohorts.
